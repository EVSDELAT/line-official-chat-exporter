# LINE 官方帳號對話匯出

Chrome 擴充功能：在 LINE 官方帳號後台的對話頁按一個按鈕，把整串對話匯出成文字檔。

## 特色

- **精確**：直接呼叫 LINE OA 後台內部訊息 API（就是後台頁面自己用的那個），時間戳、發話方向、訊息類型（文字／圖片／貼圖／影片／語音／檔案／位置）全部準確，不用捲動頁面等載入。
- **檔名含顧客名稱**：`顧客：王小明 LINE官方帳號對話 2026-10-14 13-37.txt`
- **隱私**：所有資料只存成你電腦上的 `.txt`，**不上傳到任何伺服器**。擴充功能只在 `chat.line.biz` / `manager.line.biz` 上運作。

## 安裝

1. 到 [Releases](../../releases) 下載 `line-oa-chat-exporter-v2.0.zip` 並解壓縮。
2. Chrome 開 `chrome://extensions`，開啟右上角「開發人員模式」。
3. 「載入未封裝項目」→ 選擇解壓縮後的資料夾。
4. 完成。以後開 LINE OA 後台對話頁，右下角會有紅色按鈕。

## 使用

1. 在 LINE OA 後台點進某位顧客的對話。
2. 按右下角紅色「匯出對話.txt」按鈕。
3. `.txt` 會存到你的下載資料夾。

輸出格式：

```
# LINE官方帳號對話匯出 v2.0
# 顧客：王小明
# 匯出時間：2026/10/14 下午1:37:22
# 共 79 則訊息

[2026/10/14 13:37] 顧客：王小明第一次手動連接，之後是啟動摩托車就可以自動連線麼
[2026/10/14 13:38] 客服：是的，只需要設定一次往後都會記憶的
```

## 版本紀錄

- **v2.0.0**：重寫。改打 LINE 後台內部 API（`GET /api/v3/bots/{botId}/chats/{chatId}/messages`，帶使用者自己的登入 session 分頁抓取），不再爬 DOM、不再捲動；顧客名稱取自對話頁頂部標題。
- v1.2 及更早：DOM 爬蟲版（已淘汰，曾有名稱誤判等問題）。

## 檔案說明

- `manifest.json` — Manifest V3 設定
- `content.js` — 全部邏輯（單一檔案）
- 圖示為選配：本 repo 未附圖示檔時 Chrome 會用預設圖示，不影響功能。Release 的 zip 內含圖示。

## 注意

- 一次匯出一位客人的對話；要多位就逐一切換、逐一按。
- 若按鈕顯示「LINE 登入狀態已失效」，重新登入後台後再試一次。
- LINE 後台改版可能導致 API 路徑變動，屆時需更新 `content.js` 的 `fetchAll`。
